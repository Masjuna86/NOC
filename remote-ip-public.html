Remote Public IP Static

Generate script otomatis untuk konfigurasi IP Public Static di MikroTik Anda.

Terminal Winbox
########################################################
# Open Remote Access ISP "Public IP Static" for MikroTik
# Date/Time: DD/MM/YYYY, 00:00:00
# Created By: JLA Tools Generator
########################################################

/routing table
add name=public-ip fib comment="Remote Public IP by JLA Tools"

/ip route
add check-gateway=ping gateway="192.168.10.1" routing-mark=public-ip comment="Remote Public IP by JLA Tools"

/ip firewall mangle
add action=mark-connection chain=input in-interface="ether1-ISP" new-connection-mark=public-ip passthrough=yes comment="Remote Public IP by JLA Tools"
add action=mark-routing chain=output connection-mark=public-ip new-routing-mark=public-ip passthrough=no
