Koleksi Script Backup MikroTik

Kumpulan perintah terminal untuk melakukan berbagai macam backup konfigurasi pada router MikroTik Anda.

1. Melakukan backup data PPP ke dalam file dengan format compact (ringkas).
Terminal Winbox
/ppp export compact file="Full Backup"
2. Melakukan backup seluruh data PPP ke dalam sebuah file.
Terminal Winbox
/ppp export file=Backupfull
3. Melakukan backup data PPP dan menyertakan informasi sensitif (seperti password) ke dalam file.
Terminal Winbox
/ppp export file=PPPBackup show-sensitive
4. Alternatif perintah untuk melakukan backup data PPP dan menyertakan informasi sensitif.
Terminal Winbox
/ppp export file=PPPBackup show-sensitive=yes
5. Melakukan backup seluruh konfigurasi router secara lengkap ke dalam format file (.rsc).
Terminal Winbox
/export file=FullRSC
6. Melakukan backup khusus untuk konfigurasi rule firewall mangle.
Terminal Winbox
/ip firewall mangle export file=backupMangle
7. Melakukan backup khusus untuk konfigurasi IP Route (tabel routing IPv4).
Terminal Winbox
/ip route export file=backupiproute
8. Melakukan backup khusus untuk keseluruhan pengaturan routing (OSPF, BGP, filter, dll).
Terminal Winbox
/routing export file=backupRouting
